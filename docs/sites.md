# 站点：每个站能拿到什么

说明：

- 本清单按**实际用过**的站点整理（36 个可用 + 死路清单）；抓取只碰公开页面与元数据，不下载内容。
- 类型：原创站 = 作者本人发布处；搬运/聚合站 = 转载与汇总；百科/档案 = IP 与角色资料；枢纽 = 链接聚合。
- 状态三档：可用 / 部分可用 / 死路（可用性会漂移，以最近一次实测为准）。
- **成人向平台一并收录**——溯源不挑平台。实测发现：有的搬运站整理的信息比原创站还全
  （原创站缺乏改进数据的动力）——这也是"网站同样需要这套方法"的原因之一。

| 站点 | 类型 | 能拿到什么 | 状态 |
|---|---|---|---|

| Fanbox | 订阅（Pixiv 系） | 作者主页与自述 | 可用（子域即作者自选名） |
| Patreon | 订阅 | 主页、自述、跨平台外链 | 可用（有反爬波动：先换出口/冷却，不判死） |
| Subscribestar | 订阅 | 主页、简介（平台政策变化后部分作者的去向） | 可用 |
| Fantia | 订阅（日） | 作者主页 | 可用 |
| 爱发电 | 订阅（中） | 作者页 | 待复访 |
| DLsite / ci-en | 同人贩售 | 社团/作者主页、发行信息 | 可用 |
| Iwara | 视频分享（MMD 社区） | 作者主页、视频页、站内接口 | 部分可用（未登录内容受限） |
| Newgrounds | 创作社区 | 作者页 | 可用 |
| YouTube | 视频平台 | 频道页、简介 | 可用 |

## 四、链接枢纽

| 站点 | 能拿到什么 | 状态 |
|---|---|---|
| Linktree | 页内 JSON 含全部外链，一趟拿全 | 可用 |
| Carrd | 官方链接合集页 | 可用 |

## 五、搜索引擎

| 来源 | 用途 | 状态 |
|---|---|---|
| Bing（中文源 / 国际源） | 按目标内容的语言选择源 | 可用 |
| DuckDuckGo（Lite / HTML） | 纯文本结果可直抓 | Lite 可用；HTML 端点有人机验证 |
| 百度（移动端） | 中文内容 | 部分（桌面端拦截） |
| 平台内置搜索工具 | 部分 Agent 环境自带 | 可用（注意内容过滤会拦部分查询） |

## 六、死路（实测不可用，别再投入）

- Google（JS 重定向壳，直抓为空）；
- 搜狗 / Yandex（反爬）；
- 百度桌面端、贴吧（安全验证）；
- 打包广告资源站（外壳页无内容）；
- 部分站点对游客隐藏成人内容——这属"部分可用"，不是死路；但本流程不登录，按现状对待。

（清单会持续扩充；每站的详细经验随实测更新。）
